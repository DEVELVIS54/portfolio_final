Intelligence Artificielle En cours

FasoX IA

Une solution pour que les avocats et citoyens du Burkina Faso accèdent facilement à l'expertise juridique. Au lieu de chercher manuellement dans des milliers de documents, ils posent une question et obtiennent une réponse immédiate basée sur les lois réelles du pays.

  • Recherche intelligente dans plus de 1000 passages de textes juridiques
  • Réponses instantanées et précises en francais
  • Application mobile pour smartphones (iOS et Android)
  • Streaming des réponses en temps réel pour meilleure UX
  • Gestion d'utilisateurs et sauvegarde de l'historique
  • Accessible 24/7 en production
Django PostgreSQL pgvector Flutter Redis Claude API Docker
Gestion Scolaire

GestionScolaire-Desktop

Un logiciel complet pour les écoles africaines. Gère les élèves, les notes, les frais scolaires et les rapports. Conçu pour fonctionner même sans internet stable, ce qui est crucial pour les régions avec connectivité précaire.

  • Gestion complète des élèves avec numérotation automatique
  • Entrée des notes et calcul automatique des moyennes
  • Gestion des frais d'école, paiements et reçus PDF
  • Décisions d'orientation (promotion, redoublement, exclusion)
  • Accès pour directeurs, enseignants et parents
  • Fonctionne hors ligne, synchronise quand internet est disponible
  • Interface simple et rapide, pas besoin de formation technique
Java 21 JavaFX 21 Spring Boot SQLite PostgreSQL iText 7
Biométrie En cours

Reconnaissance Faciale & Visiteurs

Un système qui identifie les personnes à partir de leur visage. Utile pour le contrôle d'accès, le suivi des visiteurs, ou la sécurité. Vous prenez une photo, le système dit qui c'est en temps réel.

  • Détecte les visages dans une image ou vidéo
  • Crée une empreinte unique pour chaque visage
  • Recherche rapide : identifie quelqu'un en moins d'une demi-seconde
  • Stockage sécurisé des données biométriques
  • Logs détaillés de qui a été identifié et quand
  • Peut s'adapter à d'autres secteurs : banques, écoles, accès VIP
Django PostgreSQL pgvector RetinaFace ArcFace FaceNet

EasyCv

Un outil pour créer un CV professionnel en 5 minutes. Vous remplissez vos infos, et l'IA génère un CV complet et bien formaté. Fini les heures perdues à mettre en page.

  • Formulaire simple pour entrer vos données professionnelles
  • IA génère le contenu et structure du CV automatiquement
  • Aperçu instantané du CV en cours de création
  • Téléchargement en PDF prêt à envoyer à des recruteurs
  • Sauvegarde de vos CVs pour modification future
  • Historique de tous vos CVs générés
Django PostgreSQL Groq API React Docker
Partage Temps Réel En cours

Elyon

Synchronisez votre presse-papiers (texte, lien, code) entre votre ordinateur et votre téléphone instantanément. Vous copiez sur PC, c'est disponible immédiatement sur votre mobile.

  • Copie-colle entre PC et mobile en temps réel (moins de 100ms)
  • Fonctionne automatiquement en arrière-plan
  • Secure : utilise authentification par code PIN
  • App mobile légère, ne consomme pas de batterie
  • Historique des échanges
  • Extensible : peut aussi partager notes, fichiers, liens
Python Flask Flutter WebSocket Docker

Site de Gestion Immobilière

Une plateforme pour publier et rechercher des biens immobiliers. Les agents peuvent lister appartements, villas et terrains. Les clients voient les annonces filtrées et les agents gèrent leurs listings.

  • Publication d'annonces immobilières avec photos et description
  • Recherche et filtres avancés (prix, localisation, type)
  • Trois rôles : clients cherchent, agents publient, admin gère
  • Chaque agent a son tableau de bord avec ses annonces
  • Statistiques : combien de vues, d'intéressés par bien
  • Système d'abonnement pour agents professionnels
